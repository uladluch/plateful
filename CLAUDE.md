# Plateful

iOS-приложение: калории и БЖУ блюд американских сетей ресторанов. Swift 6,
iOS 18+. Бэкенд — конвейер данных на Python и Supabase (проект
`tnlmtyhuuqpjwuhzximh`), приложение читает только опубликованный пак.
Рынок — только США.

## Куда смотреть

| задача | скилл / файл |
|---|---|
| что за продукт, границы MVP, принятые решения | `plateful-product` |
| данные, схема, пак, порог готовности | `plateful-data` |
| сбор и обновление базы, снимки, очередь сетей | `plateful-vacuum` |
| обновление цифр с сайта сети | `plateful-crawl` |
| вёрстка iOS | `ios-native-ui` |
| коммиты, хук, тесты, публикация пака | `plateful-workflow` |

**`backend/MAINTENANCE.md`** — состояние базы, стратегия поддержки,
очередь подключения оставшихся сетей и запаркованные с причинами. Любой
заход в данные начинать с него.

## Всегда

- Работаем прямо в `main`. Коммит и пуш на каждом законченном куске.
  Пути перечислять явно: в дереве бывает незакоммиченная работа
  параллельной сессии, чужое не забирать, `git add -A` не использовать.
- В базу — по одной задаче за раз: две временные роли Supabase разом
  роняют её предохранитель минут на десять.
- Настройка сети в базе (`chains.*`) — миграцией, не прямым `update`.
- Сайты сетей — американские, только их домен, снимки — с разрешения
  владельца. Площадки доставки не трогать, CAPTCHA не обходить, токены и
  пароли не заводить и в поля не вписывать.
- Порог готовности двигает только владелец. Сейчас держит одна свежесть
  ≥90 %, снимки сеть не держат.
- Проверка — тестами и логами, не скриншотами.
