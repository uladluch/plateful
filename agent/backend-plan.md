# Свой бэкенд с полной базой меню — план

Цель: свежий каталог калорий и макросов по ~100 сетям США, обновляемый без
релизов, стоимостью ≈ $0/мес. Замена Nutritionix ($299/мес).

Опирается на `research-2026-09-07.md`. Проверено 2026-09-07 живыми запросами.

## 0. Главная мысль: это не сервер, а конвейер

Приложению не нужен API в рантайме — ему нужен файл 0.4 MB (см. research).
Значит «бэкенд» — это **batch-конвейер**, который раз в неделю:

```
источники сетей ──► адаптеры ──► нормализация ──► валидация ──► Postgres (истина)
                                                                    │
                          приложение ◄── Storage: pack-vN.json.gz ◄─┘ экспорт
```

Ничего не должно быть «поднято» 24/7. Отсюда и стоимость ≈ 0.

## 1. Откуда брать данные — проверено на живых сайтах

Сети с 20+ точками обязаны публиковать калории (FDA menu labeling,
21 CFR 101.11). Публикуют все, но каждая по-своему. Четыре типа источников,
по убыванию удобства:

| Тип | Пример (проверено) | Как забирать |
|---|---|---|
| **JSON, встроенный в HTML** | Chick-fil-A: на странице позиции `"nutrition":[{"key":"calories","value":420},{"key":"protein","value":"29g"}…]` | curl + regex/JSON, адаптер ~40 строк |
| **`__NEXT_DATA__` / SPA-state** | Taco Bell: 589 позиций с `calories` на `/food`; макросы — по ссылке на лейбл позиции | то же |
| **Внутренний JSON-API сайта** | McDonald's `dnaapp/itemDetails` | curl с браузерными заголовками; за Akamai — Playwright |
| **PDF nutrition guide** | Subway, Panera, Burger King, большинство хвоста | pdfplumber → таблица; при кривой вёрстке — LLM-экстракция в схему |

Пятый источник — **MenuStat 2018 как seed**: все 96 сетей сразу, помечены
`stale=true`, вытесняются по мере подключения адаптеров.

### Что мешает и как обходить

Проверено: Panera отдаёт `403 Access Denied` (Akamai), McDonald's рвёт TLS-сессию
после handshake — тоже бот-защита. Это норма для крупных сетей.

- **Playwright (headless Chromium)** вместо curl — низкий объём (сотни запросов
  на сеть в неделю) обычно проходит Akamai. Запуск в GitHub Actions.
- **Вежливость**: 1 запрос/сек, честный User-Agent с контактом, robots.txt,
  никаких CAPTCHA-обходов и логинов. Это и легальнее, и меньше банят.
- **PDF как запасной путь**: у сетей за Akamai почти всегда есть PDF-гайд,
  который лежит на CDN без защиты.
- **Ручной ввод** для 2–3 сетей, где ничего не работает. Это 100–300 позиций,
  не катастрофа.

### Чего не делать

Не парсить Nutritionix, MyFitnessPal, FatSecret — это их данные, их ToS, и они
конкурируют с нами. Taco Bell хостит лейблы на `nutritionix.com` в white-label —
брать только то, что сеть отдаёт на своём домене; лейблы с чужого домена —
крайний случай с пометкой в `source`.

Юридически: пищевые факты не защищаются копирайтом (Feist v. Rural),
публикация обязательна по закону, парсинг публичных страниц без обхода защит
признан допустимым (hiQ v. LinkedIn). Названия сетей — номинативное
использование, дисклеймер уже в `description.txt`. Не юридическая консультация;
перед масштабом на 100 сетей стоит час юриста.

## 2. Схема Postgres (Supabase)

```sql
chains    (id, name, slug, source_kind, source_url, crawl_every, status)
items     (id, chain_id, ext_key, name, category, serving_text,
           kcal, protein, carbs, fat, sat_fat, sodium, sugar, fiber,
           kcal_min, kcal_max,            -- для диапазонов «730-1010»
           source, source_url, observed_at, valid_from, valid_to,
           confidence, stale)
overrides (item_id, field, value, reason, author, created_at)
crawls    (id, chain_id, started_at, finished_at, found, changed, dropped,
           status, notes)
releases  (version, pack_url, sha256, item_count, created_at)
search_events (query, chain_id, matched bool, ts)   -- анонимно, из приложения
```

Два принципа, которые сберегут месяцы:

- **`overrides` живут отдельно от `items`.** Ручная правка не должна
  затираться следующим кроулом. Экспорт накладывает overrides поверх.
- **`items` версионируются через `valid_from/valid_to`**, а не перезаписываются.
  Видно, когда Big Mac стал 580 вместо 540, и можно откатить плохой кроул.

## 3. Валидация — самая дешёвая и самая важная часть

Парсеры ломаются тихо. Ловим четырьмя проверками:

1. **Атуотер**: `kcal ≈ 4·P + 4·C + 9·F` в пределах ±20%. Ловит съехавшие
   колонки, перепутанные единицы, «g» вместо «mg». Исключения: алкоголь,
   сахарные спирты, высокая клетчатка — расширить допуск, не выключать.
2. **Диапазоны**: одиночная позиция 0–3000 ккал, макросы ≥ 0, белок ≤ 200 г.
3. **Дифф с прошлым кроулом**: изменилось >30% позиций или пропало >20% —
   кроул в `status=held`, релиз не собирается, алерт. Так редизайн сайта
   не сотрёт сеть из приложения.
4. **Диапазоны комбо** («730-1010») — хранить `kcal_min/kcal_max`, не усреднять.
   В приложении показывать «от 730».

## 4. Адаптеры — как не написать 100 парсеров руками

Единый интерфейс:

```python
class Adapter(Protocol):
    chain: str
    def fetch(self) -> list[RawItem]   # name, category, serving, nutrients: dict
```

Всё остальное — загрузка, нормализация, валидация, дифф, запись — общее.
Адаптер для JSON-в-HTML это 30–60 строк. Для PDF — общий `PdfAdapter` с
параметрами страниц/колонок.

**LLM-экстракция для PDF.** Когда таблица кривая, отдаём страницы Claude
с фиксированной JSON-схемой и прогоняем результат через Атуотер. PDF на 50
страниц ≈ 60k токенов ≈ центы на Haiku/Sonnet. 50 PDF-сетей раз в месяц —
единицы долларов. Валидация делает это безопасным: галлюцинированные цифры
Атуотер не проходят.

**LLM для написания адаптеров.** Новая сеть: скормить Claude HTML страницы
позиции и интерфейс `Adapter` — получить черновик адаптера. Хвост из 90 сетей
перестаёт быть проблемой.

## 5. Оркестрация: GitHub Actions, cron, бесплатно

```
.github/workflows/crawl.yml   — пн 06:00 UTC, matrix по сетям, Playwright
.github/workflows/release.yml — после crawl: экспорт пака, manifest, Storage
```

Free tier: 2000 минут/мес на приватный репо. 100 сетей × 3–5 мин = меньше
500 мин в неделю… это впритык. Решение: не все сети каждую неделю —
8 ключевых еженедельно, хвост раз в месяц (`chains.crawl_every`). Итого
~600 мин/мес. Если станет тесно — self-hosted runner на любом Mac/VPS.

Секреты: `SUPABASE_SERVICE_KEY`, `ANTHROPIC_API_KEY` — в GitHub Secrets,
в клиент не попадают вообще.

## 6. Экспорт и доставка в приложение

```
SELECT … FROM items LEFT JOIN overrides … WHERE valid_to IS NULL
  → pack-v{N}.json.gz  (≈0.4 MB)
  → Supabase Storage: packs/v{N}.json.gz  (immutable)
  → manifest.json: {version, url, sha256, item_count, released_at}
```

Приложение: seed-пак в бандле → при старте читает `manifest.json` (2 KB) →
если версия новее, качает пак в фоне, проверяет sha256, атомарно подменяет.
Без сети — работает на том, что есть. Supabase лёг — работает на том, что есть.

Egress: 5 GB/мес на free tier ≈ 12 000 скачиваний пака. На старте хватит;
при росте пак переезжает на Cloudflare R2 (egress бесплатный), манифест
просто меняет `url`.

## 7. Обратная связь из приложения — что чинить первым

Приложение шлёт `search_events`: запрос, выбранная сеть, нашлось или нет.
Анонимно, без аккаунта, батчем раз в день. Это единственный трафик в Supabase
из клиента, через anon key + RLS «только INSERT».

Отчёт раз в неделю: топ запросов с `matched=false` по сетям — это буквально
приоритет для следующего адаптера. Так хвост подключается не по алфавиту,
а по спросу.

## 9. План работ

**Неделя 1 — каркас на трёх сетях.**
Схема в Supabase, общий раннер, Атуотер+дифф, экспорт пака, manifest.
Адаптеры: Chick-fil-A (JSON в HTML), Taco Bell (`__NEXT_DATA__`),
одна PDF-сеть (Subway) — по одному на каждый тип источника.
Seed MenuStat 2018 залит с `stale=true`. На выходе — рабочий `pack-v1`.

**Неделя 2 — восемь ключевых сетей и автоматика.**
McDonald's, Starbucks, Chipotle, Panera, Wendy's через Playwright/PDF.
`overrides`, GitHub Actions cron, алерты в Telegram/почту при `held`.

**Дальше — хвост по спросу.** 1–2 сети в день по данным `search_events`,
адаптеры генерятся Claude по HTML. MenuStat вытесняется сеть за сетью.

## 10. Риски

| Риск | Вероятность | Что делаем |
|---|---|---|
| Редизайн сайта ломает адаптер | высокая, регулярно | дифф-проверка держит релиз; старые данные остаются валидными |
| Akamai банит Playwright | средняя | PDF-путь; снизить частоту; ручной ввод |
| Региональные меню (Калифорния ≠ Техас) | известная | v1 — национальное меню, поле `region` заложить сразу |
| Диапазоны и кастомизация (Chipotle — конструктор) | точечная | `kcal_min/max`; для конструкторов — ингредиенты как позиции |
| Юридическая претензия от сети | низкая | публичные факты, вежливый кроул, дисклеймер, снять сеть по запросу |

## 11. Что это меняет в приложении

Ничего в UI. `MenuRepository` получает вторую реализацию — «бандл или
скачанный пак, что новее». Плюс один фоновый отправитель `search_events`.
Всё остальное из предыдущего плана остаётся.
